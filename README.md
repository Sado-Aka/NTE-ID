# NTE Bahasa Indonesia — Neverness to Everness 1.3

> Patch Bahasa Indonesia tidak resmi untuk game **Neverness to Everness** (CN build).  

[![Discord](https://img.shields.io/badge/Discord-Join%20discord-5865F2?style=for-the-badge&logo=discord&logoColor=white)](https://discord.gg/rhUKsb7V8r)

---

## Persyaratan

- Game **Neverness to Everness** (CN atau Global) sudah terpasang
- Windows 10/11 64-bit

---

## Instalasi

### Langkah 1 — Unduh rilis terbaru

Buka tab [**Releases**](../../releases) dan unduh file terbaru.

Kamu akan mendapatkan:
```txt
netbios.dll
game_id.dat
id_font.ttf
```

### Langkah 2 — Letakkan file ke folder game

Salin **3 file** tersebut ke folder:
```txt
C:\Program Files\Neverness To Everness\Client\WindowsNoEditor\HT\Binaries\Win64\
```

> Ini adalah folder yang berisi file `HTGame.exe` atau `HTGame-Win64-Shipping.exe`.

### Langkah 3 — Jalankan game

Buka game seperti biasa. Patch Bahasa Indonesia akan otomatis aktif saat game dimuat.

---

## Uninstal

Hapus 3 file `netbios.dll`, `game_id.dat`, `id_font.ttf` dari folder `Win64/`.
